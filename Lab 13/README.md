# 🔌 AI Electricity Consumption Predictor  

A machine learning web application that predicts monthly household electricity usage based on home size, appliances, and usage behavior.  
The model is built using **Random Forest Regression** and deployed using **Flask**.

---

## 📌 Features

- User-friendly Web UI for input
- Predicts monthly power consumption (kWh)
- Random Forest based ML model
- Accepts appliance usage patterns as input
- Simple and lightweight Flask backend
